# One

Official One framework agent skills for web and native app development. See the [repository README](../../README.md) for project installation, Claude plugin installation, updates, and agent instructions.

Install all six skills for Codex and Claude Code from an app root:

```bash
npx skills add onejs/skills --skill '*' --agent codex claude-code --yes
```

Start a fresh agent session and use `building-with-one` before editing a One app. Use the topic skills and references relevant to the task. Check the installed One version before using newer native APIs.
